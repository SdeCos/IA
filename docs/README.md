# Documentación del parcial

Empieza por la **[checklist de entrega](CHECKLIST_ENTREGA.md)**. Distingue funciones
implementadas, decisiones que debe tomar el alumno y pruebas físicas pendientes.

| Documento | Para qué sirve |
|---|---|
| [ENUNCIADO.md](ENUNCIADO.md) | Requisitos aportados por el profesor. |
| [CHECKLIST_ENTREGA.md](CHECKLIST_ENTREGA.md) | Estado y tareas que faltan para entregar. |
| [GUIA_USO.md](GUIA_USO.md) | Uso detallado de controles, fotos, vídeo y guardados. |
| [MEMORIA.md](MEMORIA.md) | Borrador del trabajo escrito; completar con resultados y medidas reales. |
| [REGLAS.md](REGLAS.md) | Características, intervalos y justificación del clasificador. |
| [COMPROBAR_METODO_CLASICO.md](COMPROBAR_METODO_CLASICO.md) | Comprobar manualmente las reglas y entender el papel de las etiquetas. |
| [ARBOL_DECISION.md](ARBOL_DECISION.md) | Árbol principal y subárboles generados desde el código. |
| [PARAMETROS_Y_EVIDENCIAS.md](PARAMETROS_Y_EVIDENCIAS.md) | Justificación experimental de parámetros y evidencia pendiente. |
| [PRUEBAS_CASA.md](PRUEBAS_CASA.md) | Qué grabar, cómo reservar escenas y cómo evaluarlas. |
| [DEFENSA_Y_VIDEO.md](DEFENSA_Y_VIDEO.md) | Guion para la demo de 7–10 minutos y preguntas de defensa. |
| [RESPALDOS.md](RESPALDOS.md) | Copias de seguridad y traslado de los datos ignorados por Git. |
| [VERIFICACION_CODIGO.md](VERIFICACION_CODIGO.md) | Comprobaciones realizadas y sus límites. |

Para ejecutar el programa, vuelve al [README principal](../README.md). El
[mapa del código](../src/README.md) explica los paquetes y los comandos. Los
ejemplos se ejecutan desde la raíz del repositorio, no desde `docs/`.

Los archivos de `arboles/` son generados. Tras modificar las reglas, ejecuta
`./ejecutar.sh arbol` desde la raíz para actualizar esos diagramas.
