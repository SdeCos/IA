# Ejemplos de configuración

`inventario.json` contiene una unidad de cada una de las seis herramientas
originales. Es un ejemplo, no la selección definitiva del alumno.

Desde la raíz del repositorio:

```bash
./iniciar_directo.command --ultimo-video --inventario ejemplos/inventario.json
```

Puedes copiar el JSON para definir otro inventario. Las cantidades son enteros
no negativos; una clase no incluida se considera esperada cero. La opción
`--inventario` tiene prioridad sobre el perfil `config/entrega.json` guardado desde la web.

La selección de 5–8 clases para el parcial se realiza en **web → Entrega**.
Consulta el [README principal](../README.md) para cámara, fotos y evaluación.
